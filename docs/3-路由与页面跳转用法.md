# 路由与页面跳转用法

项目使用 Fluro 管理路由。

## 一、核心文件

- `lib/router/routes.dart`：路径常量与路由注册
- `lib/router/handler.dart`：每个路径对应的处理函数
- `lib/router/config.dart`：全局 `Application.router`
- `lib/bootstrap.dart`：创建并注入 router

## 二、注册流程

### 1) 路径常量

在 `Routes` 中集中定义，例如：

- `Routes.todolist`
- `Routes.fluro`
- `Routes.request`

### 2) 路由绑定

`Routes.configureRoutes(router)` 里做 `router.define(...)`。

### 3) handler 返回页面

在 `handler.dart` 中，例如：

```dart
var todolistRouteHandler = Handler(
  handlerFunc: (context, params) {
    return const PageScaffold(
      title: 'TodoList',
      widget: TodoListPage(),
    );
  },
);
```

## 三、页面里怎么跳转

示例：`lib/pages/home/index.dart`

```dart
Application.router.navigateTo(context, '/$key', transition: TransitionType.inFromRight);
```

示例：`lib/pages/fluro/index.dart`

- 传 query 参数
- 监听返回值
- 自定义转场动画

## 四、参数传递

### 传参

```dart
final route = '${Routes.transitionDetail}?message=${Uri.encodeComponent(message)}';
Application.router.navigateTo(context, route);
```

### 收参

在 handler 里从 `params` 读取：

```dart
String? message = params['message']?.first;
```

## 五、404 与函数型路由

- `router.notFoundHandler` 统一处理未匹配路由
- `dialogDemoRouteHandler` 使用 `HandlerType.function` 直接执行弹窗逻辑

## 六、你可直接照抄的新增页面步骤

1. 在 `routes.dart` 增加常量：`static const settings = '/settings';`
2. 在 `handler.dart` 增加 `settingsRouteHandler`
3. 在 `configureRoutes()` 里 `router.define(Routes.settings, handler: settingsRouteHandler)`
4. 在页面调用 `Application.router.navigateTo(context, Routes.settings)`

## 七、注意点

- 路由路径建议统一使用 `Routes.xxx` 常量，不写硬编码字符串
- 带中文/特殊字符参数时必须 `Uri.encodeComponent`
- `navigateTo(...).then(...)` 回调里先判断 `context.mounted`
