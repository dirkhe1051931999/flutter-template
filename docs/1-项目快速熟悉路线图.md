# 项目快速熟悉路线图

这份文档的目标：让你在忘掉 Flutter / Redux 语法后，能用最短路径重新建立项目全局认知。

## 你现在的项目是什么

这是一个带完整基础设施的 Flutter 模板，已经包含：

- 应用启动与 bootstrap
- Fluro 路由
- Redux 全局状态
- Dio 网络封装
- 页面与组件拆分

建议你先把它当成「Vue + TS 工程」去理解：

- `main.dart` 类似 Web 端入口
- `bootstrap.dart` 类似 `createApp()` + 插件初始化
- `router/` 类似前端路由配置
- `store/` 类似全局 store
- `api/` + `utils/request.dart` 类似 `request.ts` + `api/*.ts`

## 30 分钟快速上手（从点到面）

### 第 1 步：先跑起来，感受页面结构

1. 执行 `flutter run`
2. 进入首页（`HomePage`）
3. 点击几个入口按钮（todolist / fluro / request / profile）

关键文件：

- `lib/main.dart`
- `lib/pages/home/index.dart`

### 第 2 步：看启动链路（面向全局）

按这个顺序读：

1. `lib/main.dart`
2. `lib/bootstrap.dart`
3. `lib/layouts/index.dart`

你会看到：

- Router 与 Store 在 bootstrap 创建
- `Layout` 注入 `StoreProvider` 与 `MaterialApp`
- `onGenerateRoute` 交给 Fluro

### 第 3 步：只读一个完整业务流（点）

推荐先看 todolist（最容易）

1. 页面：`lib/pages/todolist/index.dart`
2. 组件：`lib/components/todolist_detail/*.dart`
3. action：`lib/store/todolist/type.dart`
4. reducer：`lib/store/todolist/reducer.dart`
5. 根状态：`lib/store/index.dart`

你会得到 Redux 的完整闭环：

- UI -> `store.dispatch(...)`
- action -> reducer
- reducer -> `state.copyWith(...)`
- UI 通过 `StoreConnector` 自动刷新

### 第 4 步：看网络请求流（点）

按这个顺序读：

1. `lib/utils/request.dart`
2. `lib/api/banner.dart`
3. `lib/pages/request/index.dart`
4. `lib/model/banner/index.dart`

你会得到请求闭环：

- 页面触发 API
- API 使用统一 `httpClient`
- 响应映射为 model
- 页面渲染

### 第 5 步：看路由流（点）

按这个顺序读：

1. `lib/router/routes.dart`
2. `lib/router/handler.dart`
3. `lib/router/config.dart`
4. `lib/pages/fluro/index.dart`

你会得到跳转闭环：

- 路径常量
- Handler 绑定页面
- `navigateTo` 跳转 + 参数

## 一周恢复计划（从浅到深）

### Day 1-2：语法恢复

- 熟悉 `Widget`、`StatefulWidget`、`setState`
- 熟悉 `BuildContext`、`Navigator`
- 熟悉空安全语法 `?` `!`

### Day 3：项目启动与路由

- 读懂 `main -> bootstrap -> layout`
- 读懂 `routes + handler`
- 改一个路由练手

### Day 4：Redux

- 读懂 `AppState` 和 reducer 合并
- 手写一个新 action + reducer 分支
- 在页面 dispatch + StoreConnector 回显

### Day 5：HTTP + API + Model

- 读懂 `DioClient` 拦截器
- 新增一个 API 方法
- 新增一个 model 并在页面消费
